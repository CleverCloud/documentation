The logs page of add-ons in the [Clever Cloud Console](https://console.clever-cloud.com) [moved to the new logs interface](/changelog/2025/09-12-console-addon-logs-beta/) in beta. After this testing phase, it leaves beta and replaces the previous add-on logs page for good. Add-on logs now rely on the same stack and interface as application and [access logs](/changelog/2025/09-11-access-logs-console/), built on the logs API v4.

An `Inspect` button also [shows a filtered line in context](/changelog/2025/11-28-console-logs-inspect/).

- [Learn more about logs on Clever Cloud](/doc/develop/observability/logs/)
