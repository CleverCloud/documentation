Clever Cloud now provides Redis™ [release 8.10.2](https://github.com/redis/redis/releases/tag/8.10.2). This security release prevents commands queued in a transaction from accessing keys once an ACL change revokes their permissions before execution. It also fixes crashes triggered by malformed Time Series RDB payloads, KNN queries on very long vector field names, and deeply nested JSON in Vector Set queries.

Redis™ 8.10.2 is available for new add-ons. Those already deployed can upgrade through migration.
