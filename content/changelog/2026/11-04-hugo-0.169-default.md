With the next images update, static applications will be able to use Hugo `0.168` and `0.169` through `CC_HUGO_VERSION`, and `0.169` will become the default version. If you don't set this variable, your site will build with Hugo 0.169 instead of 0.163 from your first deployment after this update. Check the release notes of the versions in between for changes that could affect your site.

From December 1, 2026, Hugo 0.168 will be the minimum supported version. If your application sets `CC_HUGO_VERSION` to an older version, set it to `0.168` or `0.169`, or remove it to use the default, then redeploy:

```bash
clever env rm CC_HUGO_VERSION
clever restart --without-cache
```

## Stay on an older version with mise

If your site needs an older Hugo version, you can install it with [mise](/doc/develop/mise/) instead. Remove `CC_HUGO_VERSION`, and `CC_DISABLE_MISE` if you set it, then add a `mise.toml` file at the root of your project and redeploy:

```toml {filename="mise.toml"}
[tools]
hugo-extended = "0.163"
```

We don't recommend it: Hugo doesn't publish a support policy for older versions, and its bug report form asks whether an issue [reproduces with the latest release](https://github.com/gohugoio/hugo/blob/master/.github/ISSUE_TEMPLATE/bug_report.md). Use this setup only to buy time while you migrate your site to a recent version.
