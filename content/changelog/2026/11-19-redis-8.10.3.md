Clever Cloud now provides Redis™ [release 8.10.3](https://github.com/redis/redis/releases/tag/8.10.3). This security-only release fixes a heap buffer overflow when a `PUBLISH` or `SPUBLISH` message larger than 4 GB propagates over the cluster bus. It only affects Redis™ in cluster mode.

Redis™ 8.10.3 is available for new add-ons. Those already deployed can upgrade [through migration](/doc/develop/database-migration/).
