We updated Redis™ to [release 8.12.0](https://github.com/redis/redis/releases/tag/8.12.0). A B+ tree encoding reduces the memory of large sorted sets, and `ZMOVE`, `BZMOVE`, and `ZMOVEMEMBER` move members between sorted sets atomically. `BITRANGEINTARRAY` returns the offsets of the set or clear bits in a range.

Set members can now expire: `SADDEX` adds members with an expiration, `SEXPIRE` and `SPEXPIRE` set it, `STTL` and `SPTTL` read it, and `SPERSIST` removes it, so a set can hold short-lived members such as sessions or tokens.

Redis™ 8.12 is available for new add-ons. Those already deployed can upgrade [through migration](/doc/develop/database-migration/).
